# Global Superstore 2016 Dashboard

This dashboard is based on the file "global_superstore_2016 (1) (4).xlsx", which contains worldwide sales, profit, and returns data for a large retail superstore in 2016. The data includes detailed order information, returns, and salespeople by region.

## Key Findings
- **Total sales:** $12,649,677
- **Total profit:** $1,473,755
- **Total unique orders:** 25,728
- **Returned orders:** 2,220 (8.6% of all orders)
- **Average discount:** 14.3%

## Dashboard Features
- **Bar Chart:** Shows the top 15 product sub-categories by total sales. You can filter the chart by "Region" using the dropdown above the chart to see which sub-categories perform best in each region.
- **Pie Chart:** Displays the distribution of profit by customer segment. Use the "Market" dropdown to filter the pie chart and see how profit is split among segments in each market.
- **KPIs and Insights:** The dashboard highlights headline numbers and key insights, and provides a preview of the first 10 orders.

The file `analysis.py` contains the full Python code used to generate this dashboard. All files are available in the GitHub folder: `reports/2026-11-14-global_superstore_2016_1_4_-7027`.
